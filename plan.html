Docusaurus Structural Layout Plan

1. Overall Codebase Structure

The Docusaurus project will be initialized in a dedicated directory (e.g., docsite/) to separate it from the main Go codebase, ensuring a clean monolithic repository structure.

  • /docsite/docs/ - The main documentation Markdown files (migrated from the root /docs/).
  • /docsite/src/ - Custom React components and styling.
  • /docsite/static/ - Static assets like images and custom text files (e.g., llm.txt).
  • /docsite/docusaurus.config.js - Core site configuration (SEO, theme config, plugins).
  • /docsite/sidebars.js - Structure of the documentation navigation.

2. Theme Separation

We will separate themes into distinct configurations:

  • Light Mode / Dark Mode: Utilize Docusaurus's native color mode toggling. Variables will be defined in CSS using :root for light mode and [data-theme='dark'] for dark mode.
  • Swizzling: Use Docusaurus swizzling only when necessary to eject or wrap existing theme components, minimizing technical debt on upgrades.

3. Design Component Style Separation

Styles will be organized to prevent global CSS pollution:

  • Global Styles: Kept minimal in src/css/custom.css for typography and basic color definitions.
  • Component-Level Styles: Use CSS Modules (e.g., MyComponent.module.css) for all custom React components in src/components/ to scope styles locally.
  • Utility Classes: Rely on Infima (Docusaurus's underlying CSS framework) utility classes for layout spacing where possible.

4. Search Capabilities

Implementing a robust search experience:

  • Fuzzy Search: We will integrate a local search plugin like @easyops-cn/docusaurus-search-local to provide offline-capable, fuzzy search out of the box without needing external Algolia configuration during development.

5. Content Migration

Existing markdown files from the repository's docs/ folder will be moved into docsite/docs/. We will update frontmatter (like id and title) and restructure them into appropriate nested categories using the sidebars.js autogenerated feature.
